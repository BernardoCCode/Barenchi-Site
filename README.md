# Site Barenchi

Site institucional em React, TypeScript e Tailwind.

## Scripts

```bash
npm run dev
npm run build
```

## Estrutura

- `src/app` — boot da aplicação, providers e rotas
- `src/pages` — páginas finas, uma por rota
- `src/modules` — módulos de domínio (`home`, `about`, `services`, `contact`, `layout`)
- `src/shared` — UI, hooks, tipos, constantes e assets reutilizáveis
- `src/styles` — CSS global e tema Tailwind
